Candidate Comparison Guide

Compare candidates with the same questions, and keep the unknowns visible.

Same questions, no scores

Comparing candidates fairly means asking each one the same set of questions. There are no scores, no rankings, and no “winner” — only a set of answers you read side by side.

The four questions

1. Where does the link open?

Confirm the current destination for each candidate. A label is not the page it opens.

2. Which options are visible?

Note color, size, and version, and what is actually selectable on each page.

3. What is the price context?

Read the currency and the time, not a bare number. A price only means something in context.

4. What is still unknown?

Keep the open items visible on each candidate. Do not fill them in to make a candidate look complete.

CompareThe same four questions, applied to every candidate, is a comparison. Anything less is a feeling.

A worked comparison

  1. Candidate A: opens on the expected page, options visible, price in context.
  2. Candidate B: opens elsewhere, one option missing, price unclear.
  3. Candidate C: opens correctly, but the version is still unknown.
